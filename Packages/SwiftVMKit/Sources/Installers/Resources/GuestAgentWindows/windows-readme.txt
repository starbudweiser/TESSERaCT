TESSERaCT guest tools for Windows

They let TESSERaCT on the Mac see the version and addresses of this machine, set its clock after it
was suspended, shut it down, share the clipboard, run commands with tctl exec, and make the display
follow the window.

To install them, plug in the virtio-win disc too (TESSERaCT does when it plugs in this one), then run
install.cmd on this disc. It asks to run as an administrator.

What the agent does is written to C:\ProgramData\TESSERaCT\agent.log.
